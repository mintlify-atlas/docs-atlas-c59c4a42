  <Accordion title="How do I format dates?">

Use [strftime](https://docs.python.org/3/library/datetime.html#strftime-strptime-behavior) in `value_template` or `date_template`:

```yaml
# Returns "20.03.2020"
value_template: '{{value.date.strftime("%d.%m.%Y")}}'
date_template: '{{value.date.strftime("%d.%m.%Y")}}'

# Returns "03/20/2020"
value_template: '{{value.date.strftime("%m/%d/%Y")}}'
date_template: '{{value.date.strftime("%m/%d/%Y")}}'

# Returns "Fri, 03/20/2020"
value_template: '{{value.date.strftime("%a, %m/%d/%Y")}}'
date_template: '{{value.date.strftime("%a, %m/%d/%Y")}}'
```

  </Accordion>

  <Accordion title="How do I show the number of days to the next collection?">

Set `value_template` within the sensor configuration:

```yaml
value_template: 'in {{value.daysTo}} days'
```

  </Accordion>

  <Accordion title="How do I show Today / Tomorrow instead of in 0 / 1 days?">

Set `value_template` within the sensor configuration:

```yaml
# Returns "Today" if value.daysTo == 0
# Returns "Tomorrow" if value.daysTo == 1
# Returns "in X days" if value.daysTo > 1
value_template: '{% if value.daysTo == 0 %}Today{% elif value.daysTo == 1 %}Tomorrow{% else %}in {{value.daysTo}} days{% endif %}'
```

  </Accordion>

  <Accordion title="How do I join waste types in a value_template?">

Use the `join` filter:

```yaml
# Returns "Garbage, Recycle"
value_template: '{{value.types|join(", ")}}'

# Returns "Garbage+Recycle"
value_template: '{{value.types|join("+")}}'
```

If you don't specify a `value_template`, waste types are joined using the `separator` configuration variable.

  </Accordion>

  <Accordion title="How do I set up a sensor which shows only the days to the next collection?">

Set `value_template` within the sensor configuration:

```yaml
value_template: '{{value.daysTo}}'
```

  <Accordion title="How do I set up a sensor which shows only the date of the next collection?">

Set `value_template` within the sensor configuration:

```yaml
value_template: '{{value.date.strftime("%m/%d/%Y")}}'
```

  </Accordion>

  <Accordion title="How do I configure a sensor which shows only the waste type of the next collection?">

Set `value_template` within the sensor configuration:

```yaml
value_template: '{{value.types|join(", ")}}'
```

  </Accordion>

  <Accordion title="How do I configure sensors which show the first, second, and third collection?">

Set `event_index` within the sensor configuration:

```yaml
sensor:
  - platform: waste_collection_schedule
    name: first_garbage_collection
    event_index: 0
    value_template: '{{value.types|join(", ")}} in {{ value.daysTo }} days'

  - platform: waste_collection_schedule
    name: second_garbage_collection
    event_index: 1
    value_template: '{{value.types|join(", ")}} in {{ value.daysTo }} days'

  - platform: waste_collection_schedule
    name: third_garbage_collection
    event_index: 2
    value_template: '{{value.types|join(", ")}} in {{ value.daysTo }} days'
```

  </Accordion>

  <Accordion title="How do I configure a sensor to show only collections of a specific waste type?">

Set `types` within the sensor configuration:

```yaml
sensor:
  - platform: waste_collection_schedule
    name: next_garbage_collection
    types:
      - Garbage

  - platform: waste_collection_schedule
    name: next_recycle_collection
    types:
      - Recycle
```

If you have set an alias for a waste type, you must use the alias name.

  </Accordion>

  <Accordion title="How can I rename a waste type?">

Set `alias` in the `customize` section of a source:

```yaml
waste_collection_schedule:
  sources:
    - name: NAME
      customize:
        - type: Very long garbage name
          alias: Garbage
        - type: Very long recycle name
          alias: Recycle
```

  </Accordion>

  <Accordion title="How can I hide a waste type I don't want to see?">

Set `show` to `false` in the `customize` section of a source:

```yaml
waste_collection_schedule:
  sources:
    - name: NAME
      customize:
        - type: Unwanted Waste Type
          show: false
```

  </Accordion>

  <Accordion title="How do I show a coloured Lovelace card depending on the due date?">

Use [Button Card](https://github.com/custom-cards/button-card) to create colour-coded cards. First, configure the sensor with a pipe-delimited template:

```yaml
# configuration.yaml
sensor:
  - platform: waste_collection_schedule
    name: MyButtonCardSensor
    value_template: '{{value.types|join(", ")}}|{{value.daysTo}}|{{value.date.strftime("%d.%m.%Y")}}|{{value.date.strftime("%a")}}'
```

Then configure the card:

```yaml
# button-card configuration
type: 'custom:button-card'
entity: sensor.mybuttoncardsensor
layout: icon_name_state2nd
show_label: true
label: |
  [[[
    var days_to = entity.state.split("|")[1]
    if (days_to == 0)
    { return "Today" }
    else if (days_to == 1)
    { return "Tomorrow" }
    else
    { return "in " + days_to + " days" }
  ]]]
show_name: true
name: |
  [[[
    return entity.state.split("|")[0]
  ]]]
state:
  - color: red
    operator: template
    value: '[[[ return entity.state.split("|")[1] == 0 ]]]'
  - color: orange
    operator: template
    value: '[[[ return entity.state.split("|")[1] == 1 ]]]'
  - value: default
```

  </Accordion>

  <Accordion title="Can I also use the Garbage Collection Card instead?">

Yes, [Garbage Collection Card](https://github.com/amaximus/garbage-collection-card) works with Waste Collection Schedule. First, configure the sensors:

```yaml
# configuration.yaml
sensor:
  - platform: waste_collection_schedule
    name: garbage_days
    details_format: appointment_types
    value_template: "{{ value.daysTo }}"
    types:
      - Garbage

  - platform: template
    sensors:
      garbage:
        value_template: >
          {% if states('sensor.garbage_days')|int > 2 %}
            2
          {% else %}
            {{ states('sensor.garbage_days')|int }}
          {% endif %}
        attribute_templates:
          next_date: "{{ state_attr('sensor.garbage_days', 'Garbage') }}"
          days: "{{ states('sensor.garbage_days')|int }}"
```

Then add the card:

```yaml
# garbage-collection-card configuration
entity: sensor.garbage
type: 'custom:garbage-collection-card'
```

  </Accordion>

  <Accordion title="How can I sort waste type specific entities?">

Add `add_days_to: true` to each sensor you want to sort. This adds a `daysTo` attribute to the entity, which you can use with [auto-entities](https://github.com/thomasloven/lovelace-auto-entities) to sort cards by the day of the next collection.

```yaml
sensor:
  - platform: waste_collection_schedule
    name: next_garbage
    types:
      - Garbage
    add_days_to: true

  - platform: waste_collection_schedule
    name: next_recycle
    types:
      - Recycle
    add_days_to: true
```

Configure auto-entities to sort by the `daysTo` attribute:

```yaml
type: custom:auto-entities
card:
  type: entities
filter:
  include:
    - entity_id: sensor.next_*
sort:
  method: attribute
  attribute: daysTo
```
