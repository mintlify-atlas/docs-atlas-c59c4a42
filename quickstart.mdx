Waste Collection Schedule supports two configuration methods. GUI configuration is recommended for most users — it requires no YAML and walks you through each step in the Home Assistant UI. YAML configuration gives you full control and is required for advanced setups such as multi-source sensors.

<Tabs>
  <Tab title="GUI (recommended)">
    The GUI configuration flow was introduced in version 2.0.0. It adds sources and sensors directly from **Settings** → **Integrations** without editing any files.

    <Steps>
      <Step title="Open integrations">
        In Home Assistant, go to **Settings** → **Devices & Services** → **Integrations**, then click **Add Integration**.
      </Step>
      <Step title="Search for Waste Collection Schedule">
        Type `Waste Collection Schedule` in the search box and click the result.
      </Step>
      <Step title="Select your country">
        Choose your country from the list. Select **Generic** if your provider is country-independent (for example, a generic ICS/iCal feed).
      </Step>
      <Step title="Select your provider">
        Choose your waste management service provider from the list of supported providers for your country.
      </Step>
      <Step title="Enter provider arguments">
        Fill in the required fields for your provider — typically your street, city, district, or postcode. The exact fields depend on the provider.

        <Tip>
          See the [Supported Providers](/providers/overview) page for a link to each provider's argument documentation.
        </Tip>

        You can also set an optional **calendar title** to give your collection calendar a friendly name.
      </Step>
      <Step title="Customize waste types (optional)">
        The integration shows you the waste types returned by your provider. For each type you can:

        - Rename it using an **alias**
        - Assign an **icon** (any `mdi:` icon)
        - Set a **picture**
        - Show or hide it
        - Create a dedicated calendar for it

        Skip this step if you want to use the default names.
      </Step>
      <Step title="Configure sensors">
        Add one or more sensors to expose collection data as Home Assistant entities:

        - Give the sensor a **name** (used as the entity name in HA)
        - Optionally filter by **waste types** to create a sensor for a specific collection type
        - Choose a **details format** (`upcoming`, `appointment_types`, `generic`, or `hidden`) for the more-info popup

        To add multiple sensors, select **Add additional sensors** before finishing the previous one.

        If you do not need any sensors, scroll down and select **Do not create sensor**.
      </Step>
      <Step title="Finish and verify">
        Click **Submit** to complete the setup. Your new source and sensors appear under **Settings** → **Devices & Services** → **Integrations**. Collection dates are also available in the **Calendar** view.
      </Step>
    </Steps>

    <Warning>
      The GUI has the following limitations compared to YAML configuration:

      - Sensors created in the GUI cannot access YAML-configured sources (and vice versa)
      - A single sensor cannot aggregate data from multiple sources (`source_index` list is not supported)
      - The `multiple` wrapper source is not supported
      - Static source configuration has limited support

      If you need any of these features, use [YAML configuration](#yaml-configuration) instead.
    </Warning>
  </Tab>
  <Tab title="YAML">
    YAML configuration gives you full control over sources and sensors. Add the following to your `configuration.yaml` file, then restart Home Assistant.

    ## Minimal example

    The example below uses `muellmax_de`, a German waste collection provider, to demonstrate a complete working configuration. Replace `muellmax_de` and its arguments with your own provider and values.

    ```yaml configuration.yaml
    waste_collection_schedule:
      sources:
        - name: muellmax_de
          args:
            service: His
            mm_frm_str_sel: My Street
          customize:
            - type: brown bin
              show: false
            - type: green bin
              alias: Yard Waste
            - type: black bin
              alias: Garbage

    sensor:
      # Next collection across all waste types
      - platform: waste_collection_schedule
        name: next_collection

      # Next yard waste collection only
      - platform: waste_collection_schedule
        name: next_yard_collection
        types:
          - Yard Waste

      # Next garbage collection only
      - platform: waste_collection_schedule
        name: next_garbage_collection
        types:
          - Garbage
    ```

    ## How the configuration works

    **Sources** define where to fetch your schedule from. Each source has a `name` (the provider module) and `args` (provider-specific arguments such as street, city, or district).

    **Sensors** expose collected data as Home Assistant entities. You can have multiple sensors per source — for example, one sensor per waste type.

    ## Using multiple sources

    If your waste is managed by more than one provider, add multiple entries under `sources`:

    ```yaml configuration.yaml
    waste_collection_schedule:
      sources:
        - name: muellmax_de
          args:
            service: His
            mm_frm_str_sel: My Street
        - name: ics
          args:
            url: https://example.com/waste-calendar.ics
    ```

    Sensors reference sources by index (0-based). To combine data from both sources into one sensor:

    ```yaml configuration.yaml
    sensor:
      - platform: waste_collection_schedule
        name: all_collections
        source_index:
          - 0
          - 1
    ```

    ## Customizing sensor state with templates

    Use `value_template` to control what the sensor displays. The following variables are available:

    | Variable | Type | Description |
    |---|---|---|
    | `value.date` | `datetime.date` | Collection date |
    | `value.daysTo` | `int` | Days until collection (`0` = today, `1` = tomorrow) |
    | `value.types` | list of strings | Waste types for this collection |

    ```yaml configuration.yaml
    sensor:
      - platform: waste_collection_schedule
        name: next_collection
        value_template: '{{value.types|join(", ")}} in {{value.daysTo}} days'

      - platform: waste_collection_schedule
        name: next_collection_date
        value_template: 'on {{value.date.strftime("%A, %d %b %Y")}}'
    ```

    <Tip>
      After editing `configuration.yaml`, restart Home Assistant or call **Developer Tools** → **YAML** → **Reload** to apply changes.
    </Tip>
